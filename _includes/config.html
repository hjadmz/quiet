{%- comment -%} quiet — the one place raw _config.yml values become safe values. Nothing else in this template reads a user-facing `site.` directly. Templates read the `q_*` variables defined here, so every setting is validated once, in one place, and a bad value can only ever produce the documented fallback — never a broken page. Three rules, applied to every setting: 1. Normalize — trim, lowercase, coerce to the expected type. 2. Fall back — an unusable value is replaced by the documented default. 3. Say so — every substitution appends one plain sentence to `q_problems`, which /site-check/ and the comment report. Silence means the config is clean. Escaping happens where a value is printed, not here, so the q_* values stay usable in both text and attribute positions. Usage: {% include config.html %} before any q_* variable is read. Cheap to repeat.

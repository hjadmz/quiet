{% comment %} Injects a quiet "#" permalink into every h2–h4 that kramdown gave an id. Pure Liquid, runs at build time, no JavaScript. Usage: {% include anchor_headings.html html=content %} Safe around code blocks: Rouge HTML-escapes code, so literal "" text inside a snippet can never match here. The permalink is beside the heading, so its accessible name cannot become part of the heading's name. Its accessible name combines the link's purpose with the heading it targets. The decorative hash is hidden from assistive technology and reader-mode extraction; the link itself stays accessible. A header keeps this introductory group intact in reader mode, which can discard short div wrappers along with the headings they contain. {% endcomment %} {%- assign _out = include.html -%} {%- assign _levels = "2|3|4" | split: "|" -%} {%- for _lv in _levels -%} {%- capture _open %}{% endcapture -%} {%- assign _parts = _out | split: _open -%} {%- if _parts.size > 1 -%} {%- capture _rebuilt -%} {{- _parts[0] -}} {%- for _p in _parts offset: 1 -%} {%- assign _tag = _p | split: '>' | first -%} {%- assign _id_parts = _tag | split: ' id="' -%} {%- if _id_parts.size > 1 -%} {%- assign _id = _id_parts[1] | split: '"' | first -%} {%- assign _segs = _p | split: _close -%}
